1프로젝트 개요

고척교회 주일·절기 예배에서 드려진 찬양대·찬양팀·특별찬양 영상을 한곳에 모아, 성도 누구나 쉽게 찾아 듣고 함께 나눌 수 있게 한 웹 아카이브 서비스입니다.

배경 & 목적

  • 10년간(2016~) 유튜브에 흩어져 있던 예배 찬양 영상을 체계적으로 정리·보존
  • 설교 본문·찬양대·날짜로 즉시 검색하여 예배 준비·묵상·나눔에 활용
  • 설치 없이 링크 하나로 접속(PWA), 고령 성도도 쉽게 쓰는 UI
  • 관리자가 유튜브 링크만 붙여넣으면 자동 등록되는 손쉬운 운영

대상 사용자

  • 성도(사용자) — 찬양 감상, 즐겨찾기, 담아듣기, 공유
  • 운영자(관리자) — 영상 등록·정리, 사용 현황 파악

4관리자(CMS) 기능

비밀번호 로그인 후 worship.onlybible.kr/admin.html 에서 운영합니다.

기능설명
🎬 원클릭 등록유튜브 링크만 붙여넣으면 제목·썸네일·재생시간·조회수 자동 채움
✏️ 편집 / 삭제 / 숨김곡명·구분·찬양대·날짜 수정, 삭제, 노출 on/off

🔄 조회수 일괄 새로고침전곡의 유튜브 최신 조회수를 50곡씩 배치로 갱신
📊 사용 현황 대시보드오늘/주간/전체 방문수·순방문자, 인기곡 TOP 10

집계는 DB 함수(RPC)로 처리해 대량 데이터에서도 빠르게 응답합니다.

7배포 · 운영

  • 서비스 주소 — worship.onlybible.kr (HTTPS 적용)
  • 자동 배포 — 코드 변경 시 GitHub Actions가 자동으로 사이트 반영
  • 캐시 버전 관리 — 배포마다 버전 태그를 올려 항상 최신본 제공(스플래시에 버전 표기)
  • 콘텐츠 갱신 — 새 예배 후 관리자에서 유튜브 링크로 즉시 추가
  • 공유 최적화 — 카카오톡 등에 전용 미리보기(OG) 카드 노출

8보안 · 개인정보

  • 사용자에게서 이름·연락처·계정 등 개인정보를 수집하지 않음
  • 방문 통계는 브라우저별 익명 식별값만 사용(개인 특정 불가)
  • 관리자 기능은 비밀번호 인증 및 서버 측 권한 검증
  • 모든 통신 HTTPS 암호화, 민감 키는 서버(시크릿)에만 보관

9향후 기획 (로드맵)

  • 테마별 찬양 모음 우선
    절기(성탄·부활·추수감사)·상황별(위로·감사·회개) 큐레이션 재생목록
  • 가사 표시 & 가사 검색 우선
    영상과 함께 가사 노출, 가사 내용으로도 검색
  • 새 영상 알림(웹푸시) 중기
    새 찬양 등록 시 구독자에게 알림(성경암송 앱의 알림 방식 재활용)
  • 상세 분석(Google Analytics) 중기
    기기·유입경로·재방문율 등 심화 통계 옵션 연결
  • 찬양대별 페이지 · QR 아이디어
    각 찬양대 전용 링크·QR로 현장 공유 강화
  • 오프라인 즐겨찾기 강화 아이디어
    네트워크가 약해도 목록·즐겨찾기 열람
우선순위는 제안이며, 운영 상황과 성도 피드백에 따라 조정합니다.
